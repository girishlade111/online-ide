## 📖 Overview

Online IDE is a browser‑based development environment that combines a **Monaco code editor** (the engine behind VS Code) with **Google Gemini‑powered AI assistance** and a **secure, production‑minded authentication layer**.

Users can:

- ✍️ **Write & run code** across 20+ programming languages with a familiar, tabbed editor.
- 🤖 **Generate new code** from a plain‑English problem description using Gemini.
- ♻️ **Refactor & improve** existing code with AI suggestions streamed back in real time.
- 🔗 **Share snippets** with anyone via a public, revocable share link — no account required to view.
- 🔐 **Sign up securely** with email + OTP verification, Google OAuth, reCAPTCHA v3 and Cloudflare Turnstile protection.

The application is split into **four independently deployable services** — a React frontend, a Node.js auth API, and two Flask micro‑services (AI + temporary file hosting) — so each piece can be scaled, restarted or secured on its own.

## ✨ Key Features

| Category | Features |
| --- | --- |
| **Editor** | Monaco editor with syntax highlighting, autocomplete, dark/light themes, per‑language starter samples, autosaved drafts in `localStorage`. |
| **AI Code Generation** | Describe a problem in natural language → streamed, language‑aware code generated by Google Gemini. |
| **AI Code Execution** | Send code + language → streamed output/analysis returned token‑by‑token. |
| **AI Refactoring** | Improve structure, readability and performance of existing code, with optional problem description context. |
| **HTML / CSS / JS Studio** | Dedicated three‑pane editor with separate generate & refactor endpoints for web projects. |
| **Sharing** | Create expiring public share links, list and revoke your own shared links from the account page. |
| **Auth** | Email/password registration with OTP verification, login, forgot/reset/change password, username changes, account deletion. |
| **Google OAuth** | One‑click sign‑in with a Google account. |
| **Abuse Protection** | Google reCAPTCHA v3 + Cloudflare Turnstile on every mutating route. |
| **Rate Limiting** | Distributed, Redis‑backed rate limits (Upstash) on the auth API, Flask‑Limiter on the Python services. |
| **Security Headers** | `helmet` sets HSTS, `X-Frame-Options`, CSP and friends; strict per‑origin CORS. |
| **Observability** | Structured JSON logging with `pino` / `pino-http`, request IDs, Python `logging`. |
| **Password Safety** | bcrypt hashing + optional [Have I Been Pwned](https://haveibeenpwned.com/) breach checks. |
| **Usage Analytics** | Per‑user counters for runs, generations, refactors and shares. |

```
                       ┌──────────────────────────────┐
                       │        Browser (React)        │
                       │  Monaco Editor · Tailwind v4  │
                       └──────────────┬───────────────┘
                                      │  HTTPS / fetch (JWT + reCAPTCHA)
        ┌─────────────────────────────┼─────────────────────────────┐
        │                             │                             │
        ▼                             ▼                             ▼
┌───────────────────┐     ┌───────────────────────┐     ┌────────────────────┐
│  Auth Service     │     │  GenAI Service        │     │  TempFile Service  │
│  Node.js/Express  │     │  Python/Flask         │     │  Python/Flask      │
│  :5000            │     │  :5001                │     │  :5002             │
├───────────────────┤     ├───────────────────────┤     ├────────────────────┤
│ JWT issuing       │     │ /generate_code        │     │ /temp-file-upload  │
│ OTP e‑mail        │     │ /get-output           │     │ /file/<shareId>    │
│ reCAPTCHA/Turnstile│    │ /refactor_code        │     │ /file/<id>/delete  │
│ Rate limiting     │     │ /improve-prompt       │     │                    │
│ HIBP checks       │     │ /htmlcssjs-*          │     │                    │
└───────┬───────────┘     └──────────┬────────────┘     └─────────┬──────────┘
        │                            │                           │
        ▼                            ▼                           ▼
┌───────────────┐          ┌──────────────────┐          ┌──────────────┐
│   MongoDB     │          │  Google Gemini   │          │  Redis       │
│  (users, logs)│          │  API             │          │  (share ids, │
└───────────────┘          └──────────────────┘          │   rate limits)│
        │                                                └──────────────┘
        ▼
┌───────────────┐
│  SMTP (Gmail) │   + Upstash Redis (distributed rate limiting)
└───────────────┘
```

![Diagram](Images/Diagram.png)

**Request flow for a typical "Run" click:**

1. Frontend attaches the JWT and a fresh reCAPTCHA token to the POST body (`apiFetch`).
2. The Flask **GenAI** service verifies reCAPTCHA and rate limits, then builds a Gemini prompt.
3. Gemini streams the response; Flask proxies the stream back with `text/plain`.
4. The frontend renders tokens as they arrive — no blocking spinner.
5. A usage counter is recorded on the **Auth** service.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/girishlade111/online-ide.git
cd online-ide
```

> 💡 Use `git clone --depth 1` if you only need the latest snapshot (skips history for a faster download).

### 2. Frontend (Vite + React)

```bash
cd Frontend
npm install
cp .env.example .env      # then fill in the values
npm run dev
```

Open **http://localhost:5173** in your browser.

### 3. Auth Backend (Node.js / Express)

```bash
cd Backend/Login
npm install
cp .env.example .env      # then fill in the values
node server.js            # or: npm start
```

Runs on **http://localhost:5000** by default (`PORT` overrides it).

### 4. GenAI Backend (Python / Flask)

```bash
cd Backend/Genai
python -m venv venv
# Windows:  venv\Scripts\activate
# macOS/Linux:  source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # then fill in the values
python app.py
```

Runs on **http://localhost:5001** by default.

### 5. TempFile Backend (Python / Flask)

```bash
cd Backend/TempFile
python -m venv venv
# Windows:  venv\Scripts\activate
# macOS/Linux:  source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # then fill in the values
python app.py
```

Runs on **http://localhost:5002** by default.

> ⚠️ **Important:** give each service a **different port**. Change one by editing the `PORT` variable:
>
> ```python
> if __name__ == "__main__":
>     app.run(debug=False, port=<port>)
> ```

### Start everything at once

Open four terminals (or use a process manager like `concurrently` / `pm2`) and run, in any order:

```bash
# Terminal 1 – Auth API
cd Backend/Login    && node server.js

# Terminal 2 – AI service
cd Backend/Genai    && python app.py

# Terminal 3 – Share service
cd Backend/TempFile && python app.py

# Terminal 4 – Frontend
cd Frontend         && npm run dev
```

## 🛡️ Security

- **Passwords** — hashed with bcrypt; optional Have‑I‑Been‑Pwned breach screening.
- **Sessions** — stateless JWTs, verified on every protected route.
- **E‑mail verification** — OTP flow before an account is activated.
- **Bot protection** — Google reCAPTCHA v3 *and* Cloudflare Turnstile on register, login, OAuth, OTP, password reset, account changes and all AI/share mutations.
- **Rate limiting** — Upstash Redis (auth API) + Flask‑Limiter (Python services), keyed per client.
- **Headers** — `helmet` supplies HSTS, `X-Frame-Options`, `X-Content-Type-Options`, CSP and referrer policy.
- **CORS** — explicit origin allowlists rather than wildcard in production.
- **Input guards** — regex validation for username/e‑mail/password plus byte‑length caps on prompts and code.
- **Secrets** — every credential lives in `.env`, which is git‑ignored; only `.env.example` placeholders are committed.

> 🔑 Generate a strong JWT secret, e.g. `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`.

## 🐛 Troubleshooting

| Symptom | Fix |
| --- | --- |
| `CORS policy` errors in the browser | Make sure `FRONTEND_URL` (Login) and `ALLOWED_ORIGINS` (Flask services) match the exact origin you're browsing from, e.g. `http://localhost:5173`. |
| `ECONNREFUSED` / Mongo timeouts | Check `MONGO_URI`, IP allow‑listing and network access on your MongoDB cluster. |
| reCAPTCHA always failing | Verify the **site key** is in `Frontend/.env` and the **secret key** is in the matching backend `.env`. |
| Turnstile "invalid key" | Site key and secret key must come from the *same* Turnstile widget. |
| Gemini returns 4xx/5xx | Confirm `GOOGLE_API_KEY`, that `GEMINI_MODEL` is a valid model ID, and that billing/quota is enabled. |
| Port already in use | Change `PORT` in the relevant `.env`, or stop the conflicting process. |
| 429 / "Too Many Requests" | Raise `RATE_LIMIT_REQUESTS` or add more Redis quota — this is the limiter working as designed. |
| Share link 404s | `TEMP_FILE_URL` must be the **publicly reachable** base URL, not `localhost`, when deploying. |
| Blank page after `npm run build` | Rebuild with `npm run build` and serve `dist/`; `npm run dev` output is not what `preview` serves. |
